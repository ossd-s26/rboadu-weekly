# Team Progress

This week, my team and I started the planning process for our open source project, affirmME. The purpose of this browser extension is to use an API that will keep track of the users completed work.When the user clicks on the extension button, it will generate a positive message that will motivate users to keep up the good work.

<!--more-->

There are not any problems that the group is currently facing. We all communicate very well with one another and take into account each other's opinions. The good aspects that are happening is that we are planning on meeting via Zoom to assign different roles for the project. We have also created a group chat via iMessage to constantly update one another as the project progresses. I plan on contributing to the project by working on the UI of the extension and potentially making sure that the API connects to the UI of the extension. I also hope to add any important files (README.md, Licesnse, etc.) to our repository.

While working with my group, it was not a discovery but a shift in mindset to really think as a developer. Last semester, I did not have many classes that involved coding and proper group collaboration so it was refreshing to get in a creative mindset and think of the steps in developing a project.
